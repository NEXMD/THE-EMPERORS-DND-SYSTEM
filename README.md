# THE EMPEROR'S DND SYSTEM

A homebrew tabletop role-playing game system: its weapons, skills, combat rules, mechanics, and balance decisions.

> **Development status:** In progress. Only confirmed decisions are documented as established rules. Unspecified values remain marked as **TBD**.

## Project sections

- **Weapon Library** — weapon identities, passive traits, active skills, and design decisions.
- **Skills & Abilities** — shared skill rules and individual ability records.
- **Combat System** — attack resolution, damage, aggro, healing, and turn structure.
- **Game Mechanics** — the wider rules that govern play.
- **Balance & Testing** — playtest observations and approved changes.
- **Visual References** — reference images and artwork used by the project.

## Design principles

1. Preserve decisions exactly once they are approved.
2. Do not invent numerical values where none have been established.
3. Keep proposed ideas separate from confirmed mechanics.
4. Record balance changes in the changelog.
