# Ideas & Development Priority List

This is an ideas and planning list. Items in this list are not automatically completed systems.

**Current development focus:** Weapon Mastery.

| Priority | System | Status | Reason |
|---:|---|---|---|
| 1 | Aggro System | Six-tier baseline documented; DM edge cases retained | Determines how enemies prioritize players through accumulated aggro and enemy behaviour. |
| 2 | Weapon Mastery | Current development focus | Adds tactical depth to every combat encounter. |
| 3 | Mana System | Planned | Fundamentally changes spellcasting. |
| 4 | Boss Adaptation | Planned | Makes major fights memorable. |
| 5 | Reputation | Planned | Makes the world respond to players. |
| 6 | Corruption | Planned | Adds risk, temptation and unique powers. |
| 7 | Expedition | Planned | Makes travelling more meaningful. |
| 8 | Conditional Advancement | Planned | Rewards memorable gameplay without excessive progression. |

## Development note

Aggro System is priority 1 and its full six-tier baseline is documented in the repository and on the website. DM-dependent decisions and unresolved edge cases remain explicitly marked. Weapon Mastery remains the system currently being developed.

This list should be revised only when the project owner changes the priorities or approves additional details.
